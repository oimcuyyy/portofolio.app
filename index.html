Keahlian Teknis & Core Stack

Teknologi utama yang saya pelajari dan terapkan dalam membangun produk web yang cepat, terstruktur, dan aman:

  • React 19 & Next.js: Arsitektur komponen modern, Server Components, manajemen state terstruktur, serta optimasi performa SSR dan SSG.
  • TypeScript: Sistem type-safety ketat untuk kode yang mudah dipelihara, scalable, dan minim bug saat runtime.
  • Tailwind CSS & Styling: Utility-first styling, tata letak responsif mobile-first, konsistensi design tokens, serta animasi Framer Motion.
  • Laravel & PHP: Pembuatan RESTful API, autentikasi aman, validasi request berlapis, arsitektur MVC, dan Eloquent ORM.
  • Supabase & BaaS: Database cloud PostgreSQL, Row-Level Security (RLS) ketat, serta integrasi server API.
  • PostgreSQL & MySQL: Pemodelan skema relasional, normalisasi tabel, indexing, dan optimasi query database.
  • Git, GitHub & Vite Tooling: Pengelolaan versi kode, alur branch, code bundling cepat dengan Vite, dan deployment otomatis ke Vercel.
